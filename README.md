# Digital Detective 🔍
> **“Think Smart. Spot the Fake.”** — *เกมการศึกษาพัฒนาทักษะการรู้เท่าทัน AI การตรวจจับกลโกงออนไลน์ และการปกป้องความเป็นส่วนตัว*

Digital Detective เป็นเว็บแอปพลิเคชันเชิงปฏิสัมพันธ์ที่ออกแบบมาเพื่อเสริมสร้างทักษะการสังเกตภาพ (Visual Literacy), การคิดเชิงวิเคราะห์ (Critical Thinking), การรู้ทันฟิชชิงและกลโกงออนไลน์ (Scam Awareness), ตลอดจนสุขอนามัยความปลอดภัยทางไซเบอร์ (Cybersecurity & Privacy Hygiene) ในธีมสีม่วง-ขาว (Purple and White Theme) ที่ทันสมัย สะอาดตา และใช้งานง่าย

---

## ✨ ภารกิจหลักทั้ง 5 ด่าน (The 5 Core Missions)

### 🕵️ ภารกิจที่ 1: AI หรือภาพจริง? (AI or Real? — The Image Detective)
- **เป้าหมาย**: ฝึกฝนการแยกแยะระหว่างภาพถ่ายจริงและภาพที่สังเคราะห์ด้วย Generative AI
- **รูปแบบการเล่น**: แสดงภาพทีละภาพ พร้อมตัวเลือก 3 แบบ:
  - ภาพสร้างโดย AI (AI-Generated)
  - ภาพถ่ายจริง (Real Photograph)
  - หลักฐานไม่เพียงพอ (Not Enough Evidence)
- **เครื่องมือเสริม**: แว่นขยายดิจิทัลความละเอียดสูง (Magnifier Loupe Zoom 2.4x) ส่องดูรายละเอียดระดับพิกเซล
- **การเรียนรู้**: แสดงคำอธิบายเบื้องหลัง แหล่งที่มา (Provenance) และใบอนุญาตของทุกภาพ

### 🧩 ภารกิจที่ 2: ปริศนาภาพ AI — เจาะลึกเบาะแส (AI Image Puzzle — Investigate the Clues)
- **เป้าหมาย**: วิเคราะห์ภาพตามสถานการณ์ไวรัล ค้นหาจุดน่าสงสัย และแยกแยะระหว่าง "เบาะแสสายตา" กับ "การยืนยันที่มา"
- **รูปแบบการเล่น**: 
  - จุดตรวจสอบเบาะแสบนภาพ (Interactive Clue Hotspots) ตรวจดูนิ้วมือ ฟันเฟือง เงาสะท้อน และตัวอักษร
  - คำถามแบบเลือกตอบเชิงวิเคราะห์ (Multiple-Choice Questions)
  - การเลือกวิธีตรวจสอบที่มาดั้งเดิม (Reverse Image Search, Content Credentials C2PA)
  - ปุ่มขอคำใบ้ (Hint) และข้อคิดประจำคดี (Detective Takeaways)

### 📱 ภารกิจที่ 3: ถอดรหัสข้อความหลอกลวง (Scam Message Decoder)
- **เป้าหมาย**: รู้ทันข้อความหลอกลวง ฟิชชิง ลิงก์อันตราย และกลโกงวิศวกรรมสังคม (Social Engineering)
- **สถานการณ์จำลอง**: SMS พัสดุตกค้าง, บัญชีธนาคารถูกระงับขอ OTP, อีเมลขู่ลบไฟล์ Cloud ใน 2 ชั่วโมง, เพื่อนทักแชตยืมเงินด่วน, รางวัลที่ไม่ได้ส่งชิงโชค, และ SMS ธุรกรรมจริงที่ถูกต้องเพื่อฝึกการแยกแยะ
- **รูปแบบการเล่น**: แตะไฮไลต์จุดอันตราย (Red Flags), จำแนกประเภท (Suspicious / Legitimate / Insufficient), และเลือกแนวทางรับมือที่ปลอดภัยที่สุด

### 🛡️ ภารกิจที่ 4: ผู้พิทักษ์ความเป็นส่วนตัว (Privacy Guardian — Protect Your Digital Identity)
- **เป้าหมาย**: เรียนรู้วิธีปกป้องรหัสผ่าน บัญชี อุปกรณ์ และข้อมูลส่วนบุคคล
- **หัวข้อสถานการณ์**: การตั้งวลีผ่านยาว (Passphrase), การเลือก 2FA ผ่าน Authenticator App, การปฏิเสธสิทธิ์แอปที่ไม่จำเป็น (App Permissions), ความเสี่ยงของ Wi-Fi สาธารณะ, การไม่เปิดเผยบาร์โค้ดตั๋วเครื่องบินบนโซเชียล, การรับมือเมื่อถูกล็อกอินจากต่างประเทศ, และควิซขโมยคำถามความปลอดภัย

### 🏆 ภารกิจที่ 5: บททดสอบยอดนักสืบดิจิทัล (Master Detective Challenge — Final Investigation)
- **เป้าหมาย**: ข้อสอบประเมินทักษะรวม 10 ข้อจากทุกหมวดหมู่ภายใต้การจับเวลาถอยหลัง 4:00 นาที
- **การประเมินอันดับนักสืบ (Detective Ranks)**:
  - 🥇 **80–100%**: ยอดนักสืบระดับมาสเตอร์ (Master Detective)
  - 🥈 **60–79%**: นักสืบชำนาญการ (Skilled Detective)
  - 🥉 **40–59%**: นักสืบสายตาไว (Junior Detective)
  - 🎖️ **0–39%**: นักสืบฝึกหัด (Rookie Detective)
- **การวิเคราะห์ผลลัพธ์**: รายงาน Category Breakdown ระบุจุดแข็งและหัวข้อที่แนะนำให้ศึกษาเพิ่มเติม พร้อมเฉลยทุกข้ออย่างละเอียด

## 📚 ศูนย์ความรู้ 7 บทเรียน (Knowledge Center)

1. **วิธีสังเกตภาพที่สร้างโดย AI**: อวัยวะที่ซับซ้อน กลไกจักรกล และตัวอักษร
2. **ทำไมเบาะแสทางสายตาจึงไม่ใช่หลักฐานเด็ดขาด**: Computational Photography, False Positives & Negatives
3. **วิธีตรวจสอบแหล่งที่มาดั้งเดิมและข้อมูล**: Reverse Image Search, Lateral Reading, มาตรฐาน C2PA
4. **วิธีจับไต๋กลโกงฟิชชิงและข้อความหลอกลวง**: การสร้างความเร่งรีบ (Urgency), โดเมนปลอม, การขู่กรรโชก
5. **การปกป้องรหัสผ่านและรหัส OTP**: พลังของ Passphrase ยาว 16+ ตัวอักษร, กฎเหล็กห้ามบอก OTP แก่ใคร
6. **การจัดการความเป็นส่วนตัวและสิทธิ์แอป**: หลัก Least Privilege, อันตรายจากการ Oversharing
7. **คิดก่อนแชร์ (Think Before You Share)**: สติและการหยุดคิดก่อนเผยแพร่ข้อมูลในยุคดิจิทัล

## 🌐 การนำขึ้น GitHub Pages (GitHub Pages Deployment)

โปรเจกต์ตั้งค่า `base: './'` ไว้ใน `vite.config.ts` เรียบร้อยแล้ว รองรับการ Deploy บน GitHub Pages ทุกรูปแบบ:

### วิธีที่ 1: Deploy อัตโนมัติผ่าน GitHub Actions (แนะนำ)
สร้างไฟล์ `.github/workflows/deploy.yml`:
```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: 'pages'
  cancel-in-progress: true

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'
      - name: Install dependencies
        run: npm ci
      - name: Build
        run: npm run build
      - name: Setup Pages
        uses: actions/configure-pages@v4
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

### วิธีที่ 2: ใช้แพ็กเกจ `gh-pages`
```bash
npm install -D gh-pages
```
เพิ่มใน `package.json`:
```json
"scripts": {
  "predeploy": "npm run build",
  "deploy": "gh-pages -d dist"
}
```
จากนั้นรันคำสั่ง:
```bash
npm run deploy
```
